# 📸 Photography Portfolio

A modern, responsive photography portfolio website built with **React (Vite)**, **Tailwind CSS**, and **JavaScript**. This project showcases a clean and elegant design, optimized for performance and accessibility, making it ideal for photographers and visual artists to display their work online.

**Live Demo:** [photography-portfolio-drab.vercel.app](https://photography-portfolio-drab.vercel.app)

---

## ✨ Features

- ⚡ **Fast and Lightweight** – Powered by Vite for rapid development and optimized builds.
- 🎨 **Tailwind CSS** – Utility-first CSS framework for efficient and customizable styling.
- 📱 **Responsive Design** – Seamless experience across desktops, tablets, and mobile devices.
- 🖼️ **Image Gallery** – Showcase your photography with a clean and organized layout.
- 🌙 **Dark Mode Support** – Optional dark mode for better viewing in low-light environments.
- 🚀 **Deployed on Vercel** – Easily accessible and shareable via a live URL.

## 🚀 Getting Started

Follow these steps to set up the project locally:

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v14 or later)
- [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/RMx-03/Photography_Portfolio.git
cd Photography_Portfolio

# Install dependencies
npm install
# or
yarn install

# Start the development server
npm run dev
# or
yarn dev
```

---

## 📸 Customization

To personalize the portfolio:
- Update Images: Replace the images in the public/assets/ directory with your own.
- Modify Content: Edit content in the components inside src/components/ and src/pages/.
- Styling: Adjust Tailwind utility classes or edit tailwind.config.js to match your style.

---

## 📤 Deployment

This project can be deployed on any static hosting platform like Vercel, Netlify, or GitHub Pages.

### Deploying to Vercel

```bash
# Optional: Install Vercel CLI
npm install -g vercel

# Deploy
vercel
```
